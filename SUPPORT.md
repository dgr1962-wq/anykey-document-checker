# Help make the next experiment reproducible

AnyKey is an independent project led by Darren Russell. Support can be funding, access, equipment, or careful technical and domain review. Please read the [Project Wish List and conditions](https://anykeycafe.com/project-wish-list/) and [contact Darren](https://anykeycafe.com/contact-contribute/) to agree on scope.

## Document Checker: the next milestones

| Milestone | Support needed | Inspectable output |
| --- | --- | --- |
| Freeze an evaluation corpus | Suitable documents and independent human reviewers | Versioned cases, provenance, labels, and handling rules |
| Run blind reviews | Model access or API credits across model families | Recorded prompts, model details, settings, and complete outputs where publication is permitted |
| Compare sequential and parallel methods | Evaluation time and analytical help | Accuracy and coverage measures, disagreements, failure cases, cost and latency observations |
| Harden the working kit | Python and evaluation contributors | Tests for malformed inputs, adversarial material, and longer documents; improved documentation |

The scope and budget of these empirical runs still need to be established. No outcome or improvement is promised in advance.

## Wider laboratory needs

- **Model access:** the wish list seeks access to nine flagship models for comparative experiments, ideally through sponsored access or credits. This is an aspiration, not a claim that nine independent evaluators are already operating.
- **Little Oogway:** a proposed dual DGX Spark setup for local memory experiments. The research aims to vary memory conditions and inspect emerging patterns, potentially using Nomic Atlas. Hardware suitability and experimental design require further evaluation.
- **Hosting and multimedia:** a **$2,000 annual planning target**, with an initial storage goal of roughly **500 GB**, expansion room, backups, and media delivery. This is the website's planning allowance, not a current vendor quote or a total budget for the lab. Local AI compute is separate.
- **Product development:** help extract working website systems into documented, tested, supportable packages. Compatibility, licensing, maintenance, and independent testing remain part of that work.

The [live wish list](https://anykeycafe.com/project-wish-list/) is the detailed reference. A concrete contribution can fund a bounded milestone; it need not fund the entire laboratory.
